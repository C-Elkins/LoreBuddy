# CurseForge Description

Use the copy below for the LoreBuddy CurseForge project page. Update the
compatibility and release-status wording when the addon has been verified in
the target client.

## Short Description

An optional, contextual, offline-first lore companion for Burning Crusade
Classic Anniversary.

## Full Description

LoreBuddy helps you understand the world around you while you play. It surfaces
the right piece of context for nearby characters, zones, factions, items,
quests, and events without forcing an encyclopedia into every moment.

The addon is designed around player control. LoreBuddy remembers what you have
discovered, supports multiple levels of detail, and hides gated spoilers by
default. You can explore more deeply when you choose.

### Features

- Contextual lore for zones, NPCs, quests, events, and related entities.
- Quick, story, and deep detail levels.
- Discovery-aware spoiler handling.
- Clear distinction between confirmed facts, interpretation, theory, and
  speculation.
- Source-aware entries with provenance and attribution information.
- Offline-first packaged data with no required internet connection.
- Optional online enrichment and AI explanation layers kept separate from the
  core addon.

### Compatibility

LoreBuddy is currently in early development and targets Burning Crusade Classic
Anniversary. The addon is not yet a finished public release. The client
interface value and in-game behavior must be verified in the installed TBC
Anniversary client before release.

### Installation

Download the release archive and place the included `LoreBuddy` folder in your
World of Warcraft `_anniversary_` AddOns directory. Enable out-of-date addons
only when the target client requires it. Release archives will be generated
from the repository packaging script so the addon contains the required TOC,
Core, and Addon files.
